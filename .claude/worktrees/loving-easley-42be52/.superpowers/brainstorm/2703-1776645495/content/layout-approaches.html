A — Cinematic Hero

Animation fills the full content-column width at the top of the page. Page title and all text scroll beneath it. First thing you see when the page loads.

Pros

  • Immediate visual impact
  • Clean reading flow below
  • Mirrors Balance-Import-Guide style

Cons

  • Long scroll to reach text
  • Animation may feel disconnected from content

B — Inline Theater

A short intro paragraph first, then the animation plays inline as a section within the content. Text continues below the animation when it finishes or loops.

Pros

  • Text sets context before animation
  • Feels natural in reading flow
  • Good for complex concepts

Cons

  • Less cinematic
  • Awkward if animation is very long

C — Persistent Stage

Animation locks to the right half of the content area. Text scrolls on the left while the animation loops in a sticky panel on the right. Both visible at once.

Pros

  • Read and watch simultaneously
  • Animation always in view
  • Feels interactive/live

Cons

  • Tight on the main column width
  • Competes with right sidebar
  • Complex to implement
