# Statement GUI Procedures

The procedure for running Employer (ER) statements out of P3 for final plan-level audits.

## Definition

Per `Statement%20GUI%20Procedures.md.txt`, the Statement GUI is the P3 interface used to schedule and run Employer Only statements against a specified date range and case number. Output is a PDF, typically emailed for review.

## Process

1. Schedule an Employer Only statement
2. Set the date range and case number
3. Run the statement
4. Email the PDF output to the requester

## Why It Matters

ER statements are the go-to plan-level snapshot for final audits. They consolidate plan-level activity for a date range and serve as a reference document when the QC or QA team is reconciling conversion outcomes.
