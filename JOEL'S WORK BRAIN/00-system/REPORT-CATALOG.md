# Report Catalog

This catalog lists the reports Joel's Work Brain can generate.

## Daily Reports

### Daily Work Map

Purpose: Tall Excalidraw-style visual of the day.

Uses:

- latest daily dump
- open reminders
- active plan statuses
- process lessons

Output folder:

- `08-reports/daily/`

### Daily Text Brief

Purpose: Fast plain-text start/end-of-day briefing.

Sections:

- Today's Brief
- Must-Do
- Watch
- Waiting On
- Wins
- Side Quest

## Weekly Reports

### Weekly Plan

Purpose: Build the next week of work.

Sections:

- Monday Launch
- Must-Win Items
- Plan Work
- Project Work
- Coverage / Out-of-Office Risk
- Stale Items
- End-of-Week Target

Output folder:

- `08-reports/weekly/`

### Friday Wrap

Purpose: Close the week and prepare Monday.

Sections:

- Done
- Still Open
- Rolled Forward
- Lessons Learned
- People to Follow Up With
- Next Monday First Moves

## Snapshot Reports

### Current Caseload Snapshot

Purpose: Show the whole plan board right now.

Sections:

- Active
- Waiting
- At Risk
- Future
- Done
- Unknowns

Output folder:

- `08-reports/snapshots/`

### Open Reminder Snapshot

Purpose: Show what needs attention based on severity and silence.

Sections:

- S1 Critical
- S2 High
- S3 Medium
- S4 Low
- Watching

## Export Reports

### Plan Profile Export

Purpose: One clean export for a single plan.

Sections:

- Status
- Key Dates
- Contacts
- Files
- Open Items
- Resolved Items
- Risks
- Next Action

### Person Profile Export

Purpose: One clean contact/context card for a person.

Sections:

- Who They Are
- Related Plans
- Open Asks
- Last Interaction
- Follow-Up Script

### Process Profile Export

Purpose: Turn a process page into a reusable job aid.

Sections:

- Rule
- Trigger
- Checklist
- Gotchas
- Related Plans

### Project Profile Export

Purpose: Turn a side project page into a concise status and direction brief.

Sections:

- Status
- Purpose
- Current Direction
- Open Items
- Related
- Why This Project Matters

Output folder:

- `08-reports/exports/`

## Leadership Reports

### Boss-Ready One-Pager

Purpose: Show useful progress without dumping details.

Sections:

- What I Improved
- What I Built
- What I Learned
- What Is Next
- Where This Helps the Team

### Leadership Demo Pack

Purpose: Package visuals, reports, and examples for a boss meeting.

Sections:

- Opening Story
- Best Visuals
- Before / After Workflow
- Current System Map
- Next Build Ideas

Output folder:

- `08-reports/leadership/`
