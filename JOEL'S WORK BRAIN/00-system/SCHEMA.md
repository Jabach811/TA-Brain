# Joel's Work Brain Schema

This vault is now plan-centric. Source files are markdown and local-first.

## Core Sections

- Plan Information: one file per plan in `02-plans/`.
- Outstanding / Open Items: generated dashboard at `open-items-dashboard.md`.
- One-off / Lessons Learned: non-plan work in `03-projects/` and durable lessons in `05-processes/`.

Deprecated active views: System, Inbox Action, Daily Dump, and raw-data storage views. Historical files can remain on disk, but they should not be used as the primary navigation model.

## Status Values

Every plan and non-plan file uses exactly one of:

- Active
- Transitioning
- Complete

## Required File Shape

Every plan and non-plan file uses this section order:

1. `# Title `case/id``
2. Metadata card
3. `## Description`
4. `## Current Updates`
5. `## Daily Updates`
6. `## Open Items`
7. `## Lessons Learned / One-offs`

## Open Items Rules

The dashboard parser depends on this exact format:

```markdown
## Open Items
- [ ] Open item text
- [x] Completed item text
```

Rules:

- Heading must be exactly `## Open Items`.
- Use `- [ ]` for open and `- [x]` for done.
- One item per line.
- No nested sub-items.
- Preserve free-form item text after the checkbox.

## Dashboard

`open-items-dashboard.md` is generated by `00-system/regenerate-open-items-dashboard.py`.

Do not hand-edit the dashboard. Edit source files and regenerate.
