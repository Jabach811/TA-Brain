# Work Brain Image Style References

Use `../IMAGE-STYLE-LOCK.md` as the source of truth.

## Current Rule

Future Work Brain images must use the cleaner long-scroll report-sheet style:

- hand-drawn whiteboard / marker look
- tall portrait or longer scroll format
- roomy sections
- yellow highlighter headings
- red circles for emphasis
- green dots for status
- content-focused doodles only
- no bottom hearts
- no decorative stars
- no top tape strips
- no taped top corners

## Reference Samples

`reference-samples/` contains the first approved structure samples.

Use them for:

- overall hand-drawn report-sheet feel
- marker outlines
- section rhythm
- icon-and-bullet storytelling
- readable visual report layout

Do not copy their older decorative habits:

- no hearts
- no decorative stars
- no top tape
- no taped top corners

The written rules in `../IMAGE-STYLE-LOCK.md` override the older sample details.
