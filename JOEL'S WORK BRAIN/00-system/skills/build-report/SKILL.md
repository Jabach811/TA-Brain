# Build Report

Use this local project skill to create reports from Joel's Work Brain.

## Required Reads

Read these first:

- `00-system/REPORT-CATALOG.md`
- `00-system/SCHEMA.md`
- `06-reminders/open-reminders.md`
- root `index.md`

Then read only the relevant object pages.

## Workflow

1. Identify report type.
2. Choose output folder under `08-reports/`.
3. Read source pages.
4. Create a concise report with clear next actions.
5. Include dates and last-mentioned values.
6. Separate active, waiting, future, done, and unknown items.
7. Update `log.md`.

## Report Defaults

- Weekly plans go in `08-reports/weekly/`.
- Current caseload snapshots go in `08-reports/snapshots/`.
- Plan/person/process exports go in `08-reports/exports/`.
- Boss or leadership outputs go in `08-reports/leadership/`.
- Daily text reports go in `08-reports/daily/`.

## Quality Bar

Every report should make Joel more ready to act. Avoid vague summaries.

Always include:

- what matters now
- what is stale
- what is waiting
- what is done
- what the next move should be
