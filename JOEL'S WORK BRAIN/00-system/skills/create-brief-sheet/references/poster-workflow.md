# Poster Workflow

Use this file when creating or refreshing Work Brain / TA Brain poster images.

## What To Read

1. Read `00-system/IMAGE-STYLE-LOCK.md` first.
2. Read `00-system/BRIEF-SHEET-STYLE.md`.
3. Read `00-system/IMAGE-SHEET-PROMPT.md`.
4. Read only the smallest set of source pages needed for the specific poster.

## Prompt Shape

Most successful prompts follow this order:

1. Lock the visual style.
2. State the poster purpose.
3. State the title, subtitle, and highlighted banner.
4. Define the numbered sections.
5. Provide exact bullets and exact circled phrases.
6. Specify the bottom flow strip or motto only if helpful.
7. Repeat the hard exclusions:
   - no hearts
   - no decorative stars
   - no top tape
   - no HTML/CSS imitation

## Content Rules

- Keep the text readable.
- Favor short bullets over paragraphs.
- Use exact names, statuses, and terminology from the source pages.
- If the poster is a sell sheet, make the value proposition explicit.
- If the poster is a how-to sheet, make the actions explicit.
- If the poster is a profile-prep sheet, ask for messy real inputs rather than polished summaries.

## Fast Quality Check

Reject and regenerate if any of these happen:

- heart doodles appear
- decorative stars appear
- tape strips or taped corners appear
- the layout feels like a dashboard, app screen, or flowchart
- the text is too small to read
- the poster looks generic instead of like the approved Work Brain sheets
