# Weekly Review

Use this local project skill for weekly planning and stale-risk review.

## Required Reads

Read these first:

- `06-reminders/open-reminders.md`
- `02-plans/_plan-index.md`
- `03-projects/_project-index.md`
- `05-processes/_process-index.md`
- `00-system/REPORT-CATALOG.md`

Then read the active plan and project pages.

## Workflow

1. Identify the review window.
2. List active, waiting, at-risk, future, and done plans.
3. Identify stale open items by severity.
4. Identify next-week deadlines and likely blockers.
5. Separate client plan work from side-project work.
6. Produce a weekly plan or Friday wrap.
7. Save the report in `08-reports/weekly/`.
8. Update reminders if items are resolved or newly stale.
9. Append to `log.md`.

## Default Weekly Report Sections

- This Week's Mission
- Plan Work
- Project Work
- People to Follow Up With
- Stale / Quiet Items
- Risk Board
- Monday First Moves
- Friday Target State
