## Description

After a plan is assigned or intake begins, the base file should become one of the first concrete work products.

## Current Updates

### Why It Matters

Base file meetings go better when the file is already prepared. Waiting creates avoidable pressure and makes it easier to get caught underprepared. Joel's shorthand from the May 5 dump: make the base file the first real move after plan intake so meetings do not catch you flat-footed.

### Trigger

Use this rule when:

- a new plan is assigned
- a base file meeting is scheduled
- client census setup is coming
- plan setup details are stable enough to begin

### Checklist

- [ ] Confirm plan treatment and setup assumptions.
- [ ] Build the base file early.
- [ ] Review for obvious missing fields.
- [ ] Bring the base file to the meeting ready to discuss.
- [ ] Send completed base file promptly after meeting.
- [ ] Capture any missing plan dates, contacts, and assumptions immediately after the meeting.
