# Reports

This folder stores generated reports from Joel's Work Brain.

## Folders

- `daily/`: daily text briefs and work-map source summaries
- `weekly/`: weekly plans, Friday wraps, Monday launch lists
- `snapshots/`: current caseload and reminder snapshots
- `exports/`: plan, person, project, and process profile exports
- `leadership/`: boss-ready one-pagers, demo packs, progress stories
- `visual/`: browser-openable drawn-style visual versions of each report type

## Rule

Reports should be generated from the markdown network, not handwritten from scratch.
