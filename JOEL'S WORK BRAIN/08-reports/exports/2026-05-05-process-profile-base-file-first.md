# Process Profile Export

Process: Base File First
Date: 2026-05-05
Type: Process Profile Export

## Rule

After a plan is assigned or intake begins, the base file should become one of the first concrete work products.

## Trigger

Use this process when:

- a new plan is assigned
- a base file meeting is scheduled
- census setup is coming
- assumptions are stable enough to begin building the file

## Checklist

1. Confirm plan treatment and setup assumptions.
2. Build the base file early.
3. Review for obvious missing fields.
4. Bring the file to the meeting ready to discuss.
5. Send the completed base file promptly after the meeting.

## Gotchas

- Waiting too long increases scramble and underprepared meetings.
- A good meeting can still turn into drag if the post-meeting send does not happen promptly.
- Sparse intake detail is not a reason to wait forever; it is a reason to build the best early version you can.
