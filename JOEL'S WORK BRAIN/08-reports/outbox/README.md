# Work Brain Outbox

Completed daily outputs go here before they are moved or synced to Google Drive.

Expected files:

- `YYYY-MM-DD-work-brain-daily-rundown.md`
- `YYYY-MM-DD-work-map.md`
- `YYYY-MM-DD-work-map.html` or image output when available

If `local_drive_outbox_path` is configured in `00-system/daily-voice-memo-config.json`, the automation should copy these files there after each successful run.
