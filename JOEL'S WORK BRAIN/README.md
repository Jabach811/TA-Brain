# Joel's Work Brain

Joel's Work Brain is a personal work operating system for tracking plan status, side projects, people, processes, reminders, and daily brain dumps.

It borrows the discipline of the TA Brain wiki ingest process, but it is separate from the official TA knowledge base. TA Brain explains the company. Joel's Work Brain explains where Joel is right now.

## Start Here

- Read `USER GUIDE.md` when you want to know how to use the system.
- Drop raw daily context into `01-daily-dumps/`.
- Track active conversion plans in `02-plans/`.
- Track side projects in `03-projects/`.
- Track useful contacts in `04-people/`.
- Track reusable ways of working in `05-processes/`.
- Review open reminders in `06-reminders/open-reminders.md`.
- Keep visual brief sheet instructions in `07-brief-sheets/`.
- Generate reports into `08-reports/`.
- Use local workflow skills in `00-system/skills/`.

## Current Operating Rule

Every new brain dump should become:

1. A daily dump summary.
2. Plan updates.
3. Project updates.
4. People/contact updates.
5. Process lessons.
6. Reminder updates.
7. A brief sheet when useful.
8. A report when useful.

## Report Factory

The report engine is documented in `00-system/REPORT-CATALOG.md`.

The core outputs are:

- daily work maps
- weekly plans
- current caseload snapshots
- stale reminder reports
- plan/person/process exports
- boss-ready one-pagers
- leadership demo packs
