# Dynamic Brain Dump Workflow

## Current Status

Working prototype; Gmail-to-Drive intake is now live as of 2026-05-06.

## Purpose

Reduce friction for capturing voice/text brain dumps by routing them through email/attachment into the brain dump folder for later processing.

## Current Direction

Joel created a shortcut that sends a brain dump directly to Gmail, where the attachment lands in the Codex Brain Dumps folder. This reduces steps and opens possibilities for automated capture, digest, and output packaging.
