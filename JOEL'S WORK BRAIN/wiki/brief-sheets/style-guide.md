## What Joel Liked

- tall format
- longer scroll format when useful
- clean hand-drawn poster style
- bright white background
- thick black marker outlines
- yellow highlight swashes behind headers
- numbered rounded panels in a two-column grid
- circle number badges
- bottom flow strip when useful
- empty checklist boxes
- big headline energy
- conversational summary
- useful reminders
- side quest section

## What To Avoid

- beige app/dashboard styling
- gradients, blur, glass, or UI chrome
- blue filled backgrounds
- checked checklist boxes
- corporate PowerPoint look
- tiny dense text
- decorative fluff with no work value
- photorealistic objects
- hearts as default bottom doodles
- decorative stars at the top, bottom, or corners
- tape strips or taped top corners
- app topbars, breadcrumb chips, dashboard cards, nested cards, or UI chrome
- HTML/CSS poster approximations

## Standard Sections

1. Header
2. The Brief
3. Checklist
4. Important Reminders
5. Process Notes
6. Fun Stuff

## Header Ideas

- Cinco de Mayo Mode
- Slow. Sharp. No shortcuts.
- Today's Work Map
- Wemby-tall edition
- Long-scroll command center

## Checklist Rule

Checklist items should be empty boxes. The image should not imply the work is already done.
