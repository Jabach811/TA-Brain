Loans / Excalidraw flow

Loan Loading

Set up P3 conversion records, run Informatica, then take over loans.

1In P3, open the plan, choose Conversions, add record keeper, enter vendor name, apply, and save.
2Create a new conversion with the case number, no affiliate, conversion date and assigned date three months before effective date, and effective date.
3Save and capture the generated conversion number.
4Validate loan header and loan source: outstanding balance in header must match source breakout.
5Run the Informatica loans workflow in test mode, then flip test to N and run production if clean.
6In P3, find the existing conversion, take over loans, handle HOLB upload/create, wait for email confirmation, and run verification queries.
