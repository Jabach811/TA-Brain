Mapping Conversion Balances

Use CONV and a dummy participant to hold fund-level purchases until final records arrive.

1Create the dummy participant before running the mapping workflow.
2Build the CONV file with case number, prior fund code, TA fund code, ref number, amount, and TIK indicator N.
3Run the day-of-wire workflow to load fund-level detail to the dummy participant.
4Process in P3 using batch no-hold and process immediate so trades go out.
5When final files arrive, run CIT balance with cash conversion wire set to N.
6Reverse the dummy participant in P3 ROC so only real participant balances remain.
