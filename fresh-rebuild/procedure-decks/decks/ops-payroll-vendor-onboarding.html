Payroll Vendor Onboarding

Payroll vendor onboarding identifies vendor and client contacts, sets up FTP, walks the vendor through the TA template, validates test files, demos the process, and hands off at go-live whether testing is complete or not.

123456
Inputs

What has to be in hand

  • Payroll vendor contact
  • Client uploader contact
  • TA payroll template
  • FTP setup request
  • Vendor test file
  • Validation results

Systems touched

FTPEDSPayroll templateOnePayrollNBIAWD
Run path

Procedure sequence

01

Identify the payroll vendor contact and the client uploader who needs FTP credentials.

02

Send the vendor intro email and fire off the FTP setup request early.

03

Hold the kickoff meeting and walk through the TA payroll template field by field.

04

Have the vendor re-tool their output and return a test file.

05

Test the FTP connection independently from the file content.

06

Run the validation chain and send issues back to the vendor until the file is clean.

07

Demo the client-facing process and prepare for go-live.

08

At go-live, hand off to Fiduciary Services through the formal process if testing is not complete.

Decision points

What decides the path

Who owns vendor file generation?
Who owns client upload access?
Is FTP ready before test-file validation?
Did the test file pass EDS and OnePayroll review?
Is payroll testing complete by go-live?
Watchouts

Where this can bite

!

FTP setup should start early because access delays are common.

!

Testing the connection is separate from validating file content.

!

Multiple payroll vendors need separate tracks.

!

Auto-sweep is later and requires several good runs.

!

DC still hands off at live even if payroll testing is incomplete.
