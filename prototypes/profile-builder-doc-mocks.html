How to read these

  • A · Capture Brief — the closest match for the page's editorial/serif voice. Best if the section is meant to feel like the company actually has a paper trail now.
  • B · Knowledge Card — closer to how the captured data will actually live in the brain (a record with metadata and links). Best if you want the frame to feel like the data is now queryable, not just filed.
  • C · Data Sheet — most stark, most "you can hand this to a system." Risk: feels colder than the rest of the page.

All three use the same migration motion: tags fly from the panel one-by-one (~80ms apart) and land in the doc. Cycle: panel fills (instant) → pause 0.6s → tags migrate → doc holds full state ~3.2s → reset.
